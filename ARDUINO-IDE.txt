ArduinoJson 7.4.2 by Benoit Blanchon is in the libraries folder. That is the library kept for these desks. It is not Arduino_JSON. This sketch does not include ArduinoJson.

Wi-Fi, HTTP, Preferences, SPI, SD, and Update come with the ESP32 board package.

Open the sketch astro_desk\astro_desk.ino. The star list, asteroid orbits, satellite paths, world picture, photo names, and the touch files are in that same folder. The touch files are XPT2046_Touchscreen.h and XPT2046_Touchscreen.cpp. They belong on this 4.3 board.

Prefs name is astro43. The first empty boot may copy Wi-Fi and place from ult43, then skywx, then ultwx. It only reads those. Factory reset clears astro43 only, and it does not copy the other desk again.

About checks GitHub. Repo https://github.com/stefi01/Astronomy-4x3-inch-display
CHECK reads ota/version.txt. INSTALL reads ota/astro_43.bin.
The partition has two app slots, app0 and app1, each 3MB. If the board has no second slot, About says no update slot.
Do not install the 7 inch bin on this screen.
